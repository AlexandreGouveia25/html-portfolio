# CELPIP Prep (backup)

Código-fonte do app de preparação para o CELPIP General.

**Versão em uso:** https://claude.ai/artifact/3nQ4kDcs7dZ1A3cpJpquXD

Este arquivo é só um backup. Ele foi feito para rodar como artefato no claude.ai,
onde tem acesso a:

- correção por IA de Writing e Speaking (capacidade `sample`)
- voz para Listening e flashcards (`tts`)
- ditado por voz no Speaking (`dictation`)
- salvamento privado na conta (`db` + `user`)

Aberto fora do claude.ai (por exemplo, no GitHub Pages), as telas, os cronômetros
e os flashcards funcionam e salvam no navegador, mas as funções de IA ficam desativadas.

Para republicar a partir deste arquivo, peça ao Claude para publicá-lo no artefato
acima com as capacidades `db`, `user`, `sample`, `tts` e `dictation`.
